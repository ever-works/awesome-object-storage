## Decentralized Storage

- [4EVERLAND](https://4everland.org) - S3-compatible object storage service compatible with AWS S3 APIs, interface operations, CLI, and other upload methods. Enables users to upload and store files from IPFS and Arweave networks in a safe, convenient, and efficient manner. ([Read more](/details/4everland.md)) `S3 Compatible` `Decentralized` `Free Tier`
- [Arweave](https://www.arweave.org/) - Arweave is a decentralized permanent information storage network that uses a pay-once economic model to support long-term availability rather than recurring cloud subscriptions. It is best suited for records intended to remain permanently addressable and publicly retrievable, such as public token metadata, governance artifacts, attestations, historical snapshots, and content where permanence is intentional. The network is immutable; updates require publishing a new version rather than overwriting existing content. ([Read more](/details/arweave.md)) `Decentralized` `Permanent Storage` `Immutable`
- [Filebase](https://filebase.com) - S3-compatible object storage service powered by blockchain technology. Offers 5 GB of free storage for an unlimited duration, providing S3 API compatibility for developers and applications. ([Read more](/details/filebase.md)) `S3 Compatible` `Blockchain` `Free Tier`
- [Filecoin](https://filecoin.io/) - Filecoin is a peer-to-peer decentralized storage network with economic incentives where clients store content with storage providers and retrieval can involve provider discovery through content identifiers and protocols including HTTP, Bitswap, and Graphsync. It is best aligned with verifiable decentralized storage deals, large content-addressed archives, public datasets, backups, and applications that value verifiable decentralized storage. The system exposes more storage-market mechanics than a conventional object-storage account. ([Read more](/details/filecoin.md)) `Decentralized` `Storage Marketplace` `P2P` `Content Addressed`
- [Pinata IPFS](https://pinata.cloud) - IPFS pinning service for uploading and managing files on IPFS. - [Storj](https://storj.io/) - Storj is a decentralized, S3-compatible object storage network that encrypts and distributes data across independent node operators. It is suitable for backup, media, and cloud-native workloads. Users pay for storage and bandwidth used. ([Read more](/details/storj.md)) `Paid` `API` `Decentralized` `S3 Compatible` `Encryption`
